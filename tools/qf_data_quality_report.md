## 三、污染实证

MA10 趋势跟踪策略跑 2020-01-01 ~ 2026-09-18，净值曲线逐日跌幅排序：

```
2026-02-03   -35.26%    <-- 正是 515880 假断层的日期
2025-09-04    -8.27%
2026-06-26    -6.33%
2025-09-02    -5.43%
```

一个 ETF 组合单日亏 35% 不可能，且日期与断层完全吻合。

## 四、根因

`data/cleaner.py` 的 `clean_etf_data()`：当 `adj_close_ref` 为 None 时
直接 `df.with_columns(pl.col('close').alias('adj_close'))`，即不复权。
本次 seed 中东方财富源全线失败（`RemoteDisconnected` / `ConnectionError`，
其 push2his CDN 屏蔽非浏览器 TLS），全部降级走 Sina 不复权价，
因此 `adj_close` 从未被真正复权。

现成的前复权源不可用：

```
510300 fund_etf_hist_em(qfq)   : ConnectionError
510300 fund_etf_hist_em(不复权) : ConnectionError
515880 fund_etf_hist_em(qfq)   : ConnectionError
```

（`fund_etf_spot_em()` 实时列表可用，但历史行情接口不可用。）

## 五、建议修法

在 `clean_etf_data()` 内增加「断层检测 + 前复权回补」：

1. 在 `close` 上计算日收益，检出 `|r| > 21%` 的断层
2. 对每个断层日 D：`factor = close[D] / close[D-1]`，
   将 **D 之前的全部价格乘以 factor**，使该日收益归零、序列连续
3. 结果写入 `adj_close`；`close` 保留原始不复权值
4. 重新 seed 以重建 `adj_close`
